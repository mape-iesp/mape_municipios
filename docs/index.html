Sobre estes dados
Painel final mape_municipios (4 Base Final/mape_municipios.parquet), consolidando as 17 dimensões. Os indicadores de "mapa", "tempo" e "relações" são uma seleção das variáveis numéricas de maior cobertura de cada dimensão (até 6 por dimensão) — não a base inteira. Valores monetários (PIB, receita total municipal) estão deflacionados (IPCA, referência dezembro de 2023, via deflateBR) — os demais valores monetários do painel completo permanecem nominais. "Por município" usa, para cada variável, o ano mais recente com cobertura de pelo menos 50% dos municípios (pode diferir entre variáveis); os demais recortes usam a média do ano escolhido. Mesorregiões e microrregiões seguem a divisão do IBGE de 2010 (última disponível). Nomes de pessoas responsáveis/validadoras não constam neste catálogo.
